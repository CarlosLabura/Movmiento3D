# TP De Movimiento 3D
Este juego es un simple prototipo de movimiento 3D alrededor de un nivel, en el cual hay que agarrar ciertos recolectables para ganar

Este projecto incluye:
- Movmiento en 3D Controlado por el jugador (Movmiento / Salto)
- Camara Modificable (Zoom) la cual sigue al jugador
- Nivel Completamente explorable
- Diferentes Coleccionables que permiten terminar el juego
